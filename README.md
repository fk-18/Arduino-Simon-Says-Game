## Project Description
The Arduino Simon Says Memory Game is an interactive memory-based game developed using Arduino UNO. The system generates a sequence of LED lights and sounds, and the player must repeat the same sequence correctly using push buttons. With every successful round, the sequence becomes longer and more difficult, improving the player’s memory and concentration skills.

An OLED display is also integrated into the project to show welcome messages, round numbers, game status, and game over notifications.

## How the Game Works
1. The OLED display shows a welcome message.
2. The game begins with a simple LED sequence.
3. The player must repeat the sequence by pressing the correct buttons.
4. If the player enters the correct sequence, the game advances to the next round.
5. Each round increases the sequence length and difficulty.
6. If the player makes a mistake, the game ends and a “Game Over” message is displayed.

---

## How to Run the Project
1. Connect all components according to the circuit diagram.
2. Open the Arduino IDE.
3. Upload the provided `.ino` code to the Arduino UNO board.
4. Power the Arduino board.
5. Follow the LED sequence and repeat it using the buttons.
